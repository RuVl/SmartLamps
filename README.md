# SmartLamp

Прошивка настольной лампы на адресной матрице WS2812B 16×16 и WeMos D1 mini (ESP8266):
эффекты, сенсорная кнопка, веб-панель настроек, MQTT и OTA. Лампа умеет работать в паре
с другой такой же — общаются по MQTT.

Что есть сейчас:

- эффекты в `src/effects/`, по файлу на эффект, саморегистрация через `REGISTER_EFFECT`;
- параметры эффектов объявляются один раз (`core::Param`) и сами становятся слайдером в
  панели, ключом в базе, топиком MQTT и полем в JSON состояния;
- веб-панель на GyverLibs Settings: WiFi, MQTT, пароль панели, журналы, OTA;
- MQTT с командами, JSON-состоянием и автообнаружением в Home Assistant;
- кнопка ttp223: касание, двойное, удержание;
- симулятор на компьютере с 2D- и 3D-видом лампы и тесты ядра на хосте.

## Сборка

```bash
pio run                       # прошивка (env d1_mini)
pio test -e native            # тесты ядра на компьютере
pio run -e sim && .pio/build/sim/program   # симулятор → http://localhost:8266

pio run -t upload
pio device monitor -b 74880
```

Пароли точки доступа, OTA и панели задаются в `secrets.ini` (скопировать из
`secrets.ini.example`). Без него действуют значения по умолчанию из `platformio.ini`.
